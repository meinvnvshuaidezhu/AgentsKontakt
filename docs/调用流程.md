## 一、项目概览

### 核心链路（三条主线）

```
① 信件投递链路（邮局管线）
agent 写 outbox\<id>.md → send.ps1（校验/编号/落 sent/原子拷贝进对方 inbox）
  → route.ps1（认领 inbox→processing + 按 registry 卡 wake 链敲门）
      ├─ exec 唤醒 → exec-dispatch-watch.ps1（进程终态观察者）
      └─ webhook / mailto 唤醒
  → agent 处理：claim.ps1 认领 → progress.ps1 心跳 → 回信写 outbox 再走 send.ps1
  → 话题完结：close.ps1 → archive.ps1（v3 状态机 / legacy 分流）→ archive\ 只读归档

② 面板数据流
托盘 exe 托管 watch.ps1（常驻守护）
  → FSW 事件（inbox/outbox 的 Renamed+Created）→ detached 派发 route/send
  → 周期 sweep：cleanup.ps1 → integrity.ps1 → Update-Dashboard → dashboard.ps1
  → 指纹门（无变化跳过）→ dashboard\dashboard.html + dashboard-data.js(+seq/version)
  → 面板 JS 每 2s probe dashboard-seq.js → 变了才 loadFull 重渲染

③ 更新链路（本轮新增）
面板 JS checkUpdate()（GitHub releases/latest，30s 超时，失败降频 6h）
  → [HOST 模式] postMessage → OnWebMessage → DownloadLoop（C# HttpClient，Range 续传）
  → DlDone → StartUpdateOrchestrator（分离进程）→ 应用退出 → Setup.exe 向导
  → install.ps1（"Install finished"）→ 删安装包 → 重拉邮差 --minimized
  → [浏览器模式] 同源 /dl-proxy 代理静默下载 / CORS 拦截 → 转交浏览器下载器
```

### 技术栈

| 层级 | 技术 |
|------|------|
| 托盘宿主 | .NET Framework 4.x（in-box csc 编译，无外部 SDK）+ WinForms + WebView2（net462 DLL 随包） |
| 邮局脚本 | Windows PowerShell 5.1（脚本树分层：根层 CLI / core 管线 / ops 运维 / tests 回归） |
| 面板 | 单文件 HTML + 原生 JS（无框架），script-tag 注入轮询（file:// 可用） |
| Python 工具 | Python 3 stdlib（poll.py 轮询门铃、test-request.py 验收发起器） |
| 通知/托盘 | 裸 Shell_NotifyIcon（NIM_ADD/MODIFY/DELETE + NIF_INFO 气泡→Win10/11 渲染为 Toast） |
| 打包 | Compress-Archive + csc（payload 内嵌 Setup.exe 单文件安装器） |

### 架构约束

- **禁止绕过邮局**：直接写别人 inbox 是最难发现的违规（dashboard 看不出异常）；投递只走 `send.ps1`
- **单写者**：agent 只写自己的 outbox\ / notes\ / registry\<自己>.md；`post\` 状态机文件 agent 不读不写不动
- **core\ 层零特例**：禁止 agent 专名与机器绝对路径（既存例外：core\dashboard.ps1 视图中心 'zcode'）；per-agent 特例进 `adapters\`
- **文案走 i18n**：控制台/sys 邮文案经 `core\i18n.ps1` 查表（`config\i18n.zh-CN.psd1`），机器面（状态值/journal 动作词/退出码）恒英文
- **改完脚本跑回归**：`scripts\tests\run-tests.ps1`（沙箱全链路，exit 0 = 全绿）；托盘 exe 改动后 `scripts\ops\build-exe.ps1`
- **数据根解析统一**：`MAILBOX_ROOT` → 向上回溯到含 `registry\` 的目录 → cwd（托盘 exe 另有五级解析，见 5.2）

## 三、安装与启动流程

### 3.1 安装链路（Setup.exe → install.ps1）

```
Setup.exe（Setup.cs Main）
  → [--silent] RunInstall()（Setup.cs）— 静默直跑
  → [向导] WizardForm.ShowDialog()（Setup.cs）
       ├── pageOptions：路径框（GetPreviousInstallDir 读注册表记忆 + \AgentsKontakt 后缀归一）
       ├── StartInstall()（Setup.cs）
       │    → StopRunningPostman()（Setup.cs）— 守卫：检测运行中的邮差
       │         ├─ 运行版 ≤ 安装器版 → AskStopRunning（结束进程继续 / 取消）
       │         └─ 运行版全部更新 → AskDowngrade（覆盖回退确认）
       │         → Kill 全部 AgentsKontaktPost + WMI 清 watch.ps1 powershell
       │    → 后台线程 RunInstall()（Setup.cs 九步管线）
       │         → 解压内嵌 payload.zip → %TEMP%\AKSetup-\<stamp>
       │         → powershell -File scripts\ops\install.ps1
       │              -InstallDir -DataDir -SourceRoot -NoAutostart（完成页决定）...
       │         → stdout 按里程碑表（copied app → ... → Install finished）推进进度条
       └── pageDone：FinishUp()（Setup.cs）
            → --register-autostart 子进程（勾选时）→ --minimized 立即启动邮差（勾选时）
```

### 3.2 install.ps1 阶段顺序（安装的真身）

```
install.ps1（ops\）
  → 1  拷代码：app\ + WebView2 DLL → <InstallDir>\app
  → 2  建数据树：mailboxes/registry/archive/logs/post\manifest/post\threads/post\cold
       templates/assets 强刷；config 仅缺时拷（system.json 用户调参不覆盖）
       scripts 装入数据目录（排除 ops 构建脚本/tests，carve-out：test-stub/test-request）
  → 2b 文档层：AGENTS/PROTOCOL/README + docs（排除 3 个 dev 文档）+ skills\mailbox
  → 2b-2 写 ~\.agents\skills\mailbox\.mailbox-root 指针（数据根定位）
  → 2c 根启动器：运行邮差.exe / 卸载.exe（Launcher.cs 编译）
  → 3   registry 卡登记（testbot 系统桩）
  → 4   快捷方式（开始菜单+桌面）→ 4b HKCU Uninstall 注册项
  → 5   autostart.ps1 -Action Register（守护计划任务 + HKCU Run 托盘双层）
  → 5b  defender-exclusion.ps1 -Action Register（一次 UAC，拒绝不影响）
  → 6   init.ps1（按 registry 建五区邮箱树）
```

### 3.3 托盘宿主启动链（每次开机/手动启动）

```
Main()（app\Program.cs）
  → 子命令分发：--install/--uninstall/--register-autostart/--register-defender-exclusion
    /--unregister-*/--version → Installer 对应方法后返回（不进 UI）
  → 单实例 Mutex（AgentsKontaktPost.SingleInstance）：活实例存在 → Set 显示信号 + return 0
  → WinForms 初始化 → ResolveDataDir()（五级：--data → MAILBOX_ROOT → 便携布局
    （含 scripts\+mailboxes\）→ <install>\data → %LOCALAPPDATA%\AgentsKontakt）
  → 数据根缺 scripts\ → 报错 return 2
  → new PostApp(installDir, dataDir, args)（app\Program.cs ctor）+ Application.Run

PostApp 构造（app\Program.cs ctor）
  → 存路径 + 建 logs 目录 + 解析 --minimized
  → TLS1.2 + 清扫 updates\ 残留（上次崩溃/中断的半成品）
  → ShellForm（AllowVisible 可见性门）+ FormClosing/SessionEnding 挂接
  → WebView2 控件 + BuildSplash()（加载遮罩）

       powershell -File scripts\watch.ps1 -Root <data>

         宿主崩溃内核回收整棵 powershell 树）
  → [AK_NOWEBVIEW=1 跳过 / minimized 延迟] InitWebAsync()
  → trayOnce(4s)：TrayIconRegistered 验证，未登记 → RemoveTray+CreateTray
  → showSignal 后台线程：第二次启动 → 唤醒已运行实例亮窗

### 3.4 daemon 启动链（watch.ps1，邮局常驻）

```
watch.ps1（core\）
  → 单实例互斥 Global\AKWATCH_<md5(root)> → 持锁收养（杀残留 watch）
  → Initialize-Tree → 读 poll_hooks 门铃配置 → 读 audit_notify_minutes
  → FileSystemWatcher：只订阅 mailboxes\ 下 Renamed+Created 的 *.md（64KB 缓冲）
       ├─ inbox\ 命中 → detached route.ps1 + 门铃待发
       └─ outbox\ 命中 → detached send.ps1（.tmp→.md 重命名即取件铃）
  → Invoke-Sweep 阶段（事件后 120s / 空闲 300s 周期）：
       ① Get-MailboxScan（AkScan C# 编译遍历，单次全量指纹）
       ② Invoke-MonitorInflight（sent 在途镜像 post\inflight.ledger；超时盖 STALLED+告警信）
       ③ 扫 outbox（take 铃）→ 扫 inbox（route，跳 sys-*、busy 预检、PULL 不重复派发）
       ④ cleanup.ps1（进程内）⑤ integrity.ps1 ⑥ Update-Dashboard → CPU 遥测
  → watch.heartbeat 每 5s（面板判活 + 托盘 MonitorTick 的 office-alive 门）
```

## 四、信件生命周期（邮局管线）

### 4.1 投递（send.ps1）

```
send.ps1 -File <outbox>\<id>.md（agent CLI 真身，v2/v3 双流）
  → Gate0 编码校验+补 BOM → Gate0b id/created/正文校验
  → A6 时钟职责：drift>24h 退信、>2min 归一化（created_original 保留原值）+ taken_at 盖章
  → type/subject≤60/to≠from/id ASCII 校验
  → Gate1 防伪造（from 必须 = outbox 属主）→ Gate1b 收件人已注册 + id 不重复
  → Gate1c related_topic 必须在 archive 中（引用旧话题开新题）
  → [v3 分支：post\threads\<topic>\status.json 存在]
       → Add-ThreadEntry()（core\threads.ps1）— 锁内追加轮次（answer→answered / question→pending）
       → Move-MasterToSent()（send.ps1）— 正本入 sent（防同 id 覆盖：旧件隔离 post\cold+.why.md）
       → Copy-ThreadChainTo()（core\threads.ps1）— 链拷贝 <topic>.chain.md 进对方 inbox
       → answer 时 Clear-ThreadCopies()（core\threads.ps1）— 双方旧链副本零痕迹清除
       → route.ps1 敲门 → 回执 sys 邮（[DELIVERED]）
  → [legacy 分流：无 status.json]
       → master 入 sent（DISPATCHING）→ Copy-MailAtomic()（core\common.ps1）进对方 inbox
       → 子进程 route.ps1 → 失败分流：busy（留对方 inbox 等自取）/ dead（拉回 + RETURNED 退信）
       → 成功盖 DELIVERED + post\manifest\<topic>.manifest（SHA256）+ reply 时 master 翻 REPLIED
```

### 4.2 路由与唤醒（route.ps1）

```
route.ps1 -File <inbox>\<id>.md（core\）
  → PULL agent（wake 空/TODO）→ WARN-once 标志，信留 inbox（agent 自取）
  → 守门 1（唤醒配额穷尽）：数 .progress 的 DISPATCHED 行 ≥ dead_after_dispatches(3)
       → A5 journal REPLIED 对账（已答→静默隔离）
       → Test-AgentBusy()（core\common.ps1）— 对方活跃 → DEFERRED 延后
       → topic 已被回 → 静默隔离
       → 否则 copy+sidecar → post\trash、master 盖 RETURNED、发退信 sys 邮并递归 route 自己
  → 守门 2（忙碌）：Test-AgentBusy() → QUEUED-BUSY 不敲门
  → 认领：Move-Atomic inbox→processing（move 即互斥）+ sidecar 随迁
       → 写首条 DISPATCHED 心跳 + Update-RegistryField last_seen + journal CLAIM
  → 唤醒链按序（exec > webhook > mailto）：
       ├─ exec：读 templates\dispatch-prompt.txt + base64 payload
       │    → detached core\exec-dispatch-watch.ps1（宽限 ExecProbeMs=3000ms 内轮询
       │      .progress 的 STATUS 行判秒死；长会话不等待，终态由观察者后写）
       ├─ webhook：POST JSON → ├─ mailto：config\smtp.json SMTP
       └─ a2a/mqtt/im：明确跳过（未实现，见第十一章）
  → 全链失败 → .progress 盖 STATUS failed + 信退回 inbox；成功 → journal DISPATCH
```

### 4.3 认领与心跳（claim.ps1 / progress.ps1）

```
claim.ps1 -File <inbox>\<id>.md
  → [v3 链] 原地状态翻转 pending→processing + status.json.last_heartbeat
  → [普通信] Move-Atomic inbox→processing + sidecar 随迁 + last_seen + journal CLAIM
progress.ps1 -File <processing>\<id>.md -Note "...（每个关键节点一条）
  → [v3] 刷 status.json.last_heartbeat + journal PROGRESS
  → [legacy] 追加 <id>.progress 行 + journal PROGRESS
（心跳 = 活体信号：cleanup 判 stale、route 判 busy、面板判「正在处理」都读它）
```

### 4.4 结案与归档（close.ps1 → archive.ps1）

```
close.ps1 -Topic <t-...> -Agent <发起者>
  → archive.ps1（67 行分流入口）
       → [v3：status.json 存在] initiator 门（非发起者 → DENIED + ARCHIVE-DENIED 信）
         → 仅 answered/archived 可归档 → Invoke-TopicArchive()（core\threads.ps1）：
              topic 锁 → 盖 archived → 链+status.json 移 archive\<from>\<yyyy>\<MM>\<dd>\<topic>\
              → 逐件 SHA256 manifest → summary.md → archive\index.jsonl（锁内幂等行替换）
              → Update-ArchiveIndexes()（core\common.ps1）重建 index.md/_index.md
              → Protect-TopicDir() 只读锁定 → 清空 thread 目录 → ARCHIVED sys 邮 → Update-Dashboard

### 5.5 下载状态机（Update Download，字段前缀 dl*）

```
面板 postMessage {action} → OnWebMessage（app\Program.cs）分派：
  download-update{url,name} → StartDownload()：
      单飞守卫（dlActive/dlFinishing）→ updates\ 目录 → 清旧半成品（退出即丢进度）
      → Task.Run DownloadLoop(false) → StartDlWatchdog（3s tick，30s 无字节=失败）
  dl-pause → PauseDownload()（BreakConnection 断流，循环 catch 收尾 DlPostPaused）
  dl-resume → ResumeDownload()（Range: bytes=N-；206 追加续传 / 200 归零重下）
  dl-cancel / dl-abandon → CancelDownload()（循环活着→signal+catch 收尾；
      已暂停（循环已退）→ 内联 DiscardPartial + DlPostCancelled）
  dl-state → 回发当前状态（面板从挂起恢复后重同步）
DownloadLoop 出口四态：
  dlDiscard → DiscardPartial + DlPostCancelled
  dlPaused → DlPostPaused
  长度不足 → DlFail("connection closed early")
  完成 → DlDone
DlDone：dl-done 回发 → 气泡 → StartUpdateOrchestrator → dlPath 移交 → 1.2s 后 ReallyQuit
DiscardDownload（面板隐藏/重载/退出）：dlLoopAlive 分流（活着 signal / 死了内联删）；
  dlFinishing 保护已完成的包（所有权已移交编排器）
进度回发：MaybeReportProgress（250ms 节流）→ DlPostJson → PostWebMessageAsJson
  （BeginInvoke 切 UI 线程）
```

## 七、更新流程（检查→下载→安装）

### 7.1 检查阶段

```
面板加载 → checkUpdate(false)（templates\dashboard-template.html）
  → fetch api.github.com/releases/latest（30s AbortController 超时）
  → 成功：latest/setupUrl(assets 里 *-Setup.exe)/notes → 30min 后重查
  → 失败/超时：lastFailed=true → 6h 后重查（静默，红点不亮）
打开弹窗（openUpdateDialog）→ 无条件强制重查一次（除 checking/下载中）
红点判定：hasUpdate()（cmpVer(latest, APP_VERSION)>0）且 latest≠ignoredVersion
  → 徽标红点 + HOST.postMessage update-available（每版本去重）→ 托盘徽标+系统通知
```

### 7.2 下载阶段（HOST 模式，托盘面板主路径）

```
点更新 → startDownload → postMessage download-update → OnWebMessage → StartDownload
  → DownloadLoop（HTTP 200；Range 续传 206 追加/200 归零）
  → 进度回发 250ms 节流 → 面板进度条（定长+流光）
暂停（进入下载进度后）→ dl-pause → 断流保字节 → dl-paused → 继续 → Range 续传
等待响应阶段（total 未知）点暂停 → 面板直接 cancelDownload（=取消）
取消/关闭弹窗/面板隐藏/应用退出 → 丢弃全部进度（DiscardPartial）
30s 无字节 → dlStall → dl-error → 面板红字失败视图
```

### 7.3 安装阶段（完成后的编排）

```
DlDone → dl-done 回发（面板"即将退出应用并打开安装程序"）→ 气泡
  → StartUpdateOrchestrator（分离进程）→ ReallyQuit（Job 对象带走 daemon 树）
编排器：Setup.exe 向导（预填本机目录）-Wait → install-*.log 检索 "Install finished"
  → 命中 → 删安装包 → 无邮差进程 → 重拉 --minimized
向导内守卫：StopRunningPostman（结束进程确认 / 版本回退确认）→ install.ps1 九步
```

### 7.4 浏览器模式降级（无 WebView2 宿主）

```
http(s) 托管：同源 /dl-proxy?url= 静默 fetch（预览服务器/自建部署实现该端点）
file://：直连 GitHub 被 CORS 拦 → browserFallbackAnchor（window.open 转交浏览器下载器）
完成 → Blob + a.download 存默认下载目录 → 提示手动运行（无宿主无法自动编排）
```
